# Phase 9 — 공유

## 목표

**명소와 코스를 링크로 공유할 수 있다.**

## 이 단계에서 만드는 것

| 기능 | PRD 번호 |
|---|---|
| 명소 상세 공유 (링크 복사) | S-09 |
| 코스 상세 공유 (링크 복사) | S-09 |

> 링크 복사 외 다른 공유 채널(SNS 등)은 만들지 않는다 (PRD 5장).

## 하는 일

### 1. 명소 상세 공유

- Phase4의 명소 상세 화면에 공유 버튼을 추가한다. 클릭하면 현재 화면 URL을 클립보드에 복사한다.

### 2. 코스 상세 공유

- Phase8의 코스 상세 화면에도 동일하게 공유 버튼을 추가한다. `GET /courses/{courseId}/share` (계획)로 공유용 URL을 받아 복사한다.

### 3. 비로그인 확인

- 공유받은 사람이 로그인 없이 내용을 볼 수 있는지 확인한다. 명소 상세·코스 상세는 이미 비로그인으로 접근 가능한 화면이므로 별도 처리는 필요 없다.

## 완료 기준 체크리스트

- [ ] 명소 상세에서 공유 버튼을 누르면 링크가 복사된다
- [ ] 코스 상세에서도 동일하게 동작한다
- [ ] 복사된 링크를 로그인 없이 열어도 내용이 보인다
- [ ] 링크 복사 외 다른 공유 버튼(SNS 등)이 없다
- [ ] `npm run lint`, `npm run build` 통과

## 넘어가기 전 확인

- 리뷰 공유는 PRD에 언급은 있으나 이번 Phase에서는 명소·코스만 다룬다. 필요해지면 별도로 논의 후 추가한다.
