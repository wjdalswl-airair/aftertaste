# Phase 9 — 공유

## 목표

**명소와 코스를 링크로 공유할 수 있다.**

> (2026-08-31 변경) "코스 상세 공유"는 Phase8로 앞당겨서 이미 구현했다(코스 상세 화면 자체를 Phase8에서 만들면서 같이 처리하는 게 자연스러워서). "명소 상세 공유"는 사실 Phase4에서 명소 상세 화면을 만들 때 이미 함께 구현되어 있었다(`SpotDetailPage.tsx`의 `handleShare`). 그래서 이 Phase는 **새로 만들 게 없고, 기존 구현이 완료 기준을 만족하는지 확인만** 하면 된다.

## 이 단계에서 만드는 것

| 기능 | PRD 번호 | 상태 |
|---|---|---|
| 명소 상세 공유 (링크 복사) | S-09 | Phase4에서 이미 구현됨 |
| 코스 상세 공유 (링크 복사) | S-09 | Phase8에서 이미 구현됨 |

> 링크 복사 외 다른 공유 채널(SNS 등)은 만들지 않는다 (PRD 5장).

## 하는 일

### 1. 명소 상세 공유 — 확인만

- `SpotDetailPage.tsx`에 이미 있는 공유 버튼(현재 URL 클립보드 복사)이 완료 기준을 만족하는지 확인한다.

### 2. 코스 상세 공유 — 확인만

- Phase8에서 만든 코스 상세 화면의 공유 버튼이 동일하게 동작하는지 확인한다.

### 3. 비로그인 확인

- 공유받은 사람이 로그인 없이 내용을 볼 수 있는지 확인한다. 명소 상세·코스 상세는 이미 비로그인으로 접근 가능한 화면이므로 별도 처리는 필요 없다.

## 완료 기준 체크리스트

- [x] (코드로 확인, 브라우저 확인 필요) 명소 상세에서 공유 버튼을 누르면 링크가 복사된다 (`SpotDetailPage.tsx` `handleShare`, Phase4)
- [x] (코드로 확인, 브라우저 확인 필요) 코스 상세에서도 동일하게 동작한다 (`CourseDetailPage.tsx` `handleShare`, Phase8)
- [x] 복사된 링크를 로그인 없이 열어도 내용이 보인다 — 두 라우트(`/spots/:placeId`, `/courses/:courseId`) 모두 `RequireAuth` 밖에 있어 비로그인 접근 가능
- [x] 링크 복사 외 다른 공유 버튼(SNS 등)이 없다
- [x] `npm run lint`, `npm run build` 통과

## 넘어가기 전 확인

- 리뷰 공유는 PRD에 언급은 있으나 이번 Phase에서는 명소·코스만 다룬다. 필요해지면 별도로 논의 후 추가한다.
