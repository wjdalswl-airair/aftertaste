# Phase 7 — 마이페이지 · 회원탈퇴

## 목표

**로그인한 사용자가 내 정보를 보고 관리하고, 탈퇴할 수 있다.**

## 이 단계에서 만드는 것

| 기능 | PRD 번호 |
|---|---|
| 마이페이지 (프로필/즐겨찾기/내 리뷰/국적,언어) | S-10 |
| 프로필·국적·언어 수정 | S-10 |
| 회원탈퇴 | S-11 |

## 하는 일

### 1. 마이페이지

- `GET /api/account/` (확정)로 기본 정보, `GET /account/reviews` (계획)로 내가 쓴 리뷰, Phase5에서 만든 `GET /account/bookmarks`로 즐겨찾기 목록을 함께 보여준다.
- 저장한 코스 자리는 만들어두되, 비어 있어도 된다 (코스는 Phase8).

### 2. 프로필·국적·언어 수정

- `PATCH /api/account/` (계획, 닉네임 등 프로필), `PATCH /account/locale` (계획, Phase2에서 만든 것과 같은 API)로 국적·언어를 마이페이지에서도 바꿀 수 있게 한다.

### 3. 회원탈퇴

- `DELETE /account` (계획). 성공하면 로그아웃 처리하고 첫 화면으로 보낸다.

## 완료 기준 체크리스트

- [ ] 마이페이지에서 프로필, 즐겨찾기 목록, 내가 쓴 리뷰, 국적/언어 설정이 보인다
- [ ] 저장한 코스 자리가 있다 (비어 있어도 됨)
- [ ] 프로필(닉네임)을 수정하면 반영된다
- [ ] 국적/언어를 마이페이지에서 바꿀 수 있다
- [ ] 탈퇴 버튼을 누르면 탈퇴 처리되고 로그아웃 상태로 돌아간다
- [ ] 비로그인 상태로 마이페이지에 접근하면 로그인으로 유도된다
- [ ] `npm run lint`, `npm run build` 통과

## 넘어가기 전 확인

- 탈퇴 전 확인 절차·안내 문구는 PRD에서도 "추후 추가"로 남겨둔 부분이다. 최소한의 확인(정말 탈퇴할지 한 번 묻는 정도)만 넣고 과하게 만들지 않는다.
- 탈퇴한 사용자가 쓴 리뷰는 "탈퇴한 사용자"로 표시된다(BE가 처리). FE가 별도로 숨기거나 지우지 않는다.
- 탈퇴 후 같은 계정으로 다시 로그인하면 새 회원으로 시작한다(BE 규칙). FE는 특별한 분기 없이 Phase1의 로그인 흐름을 그대로 타면 된다.
