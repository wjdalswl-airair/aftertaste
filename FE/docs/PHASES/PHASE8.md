# Phase 8 — 코스

## 목표

**명소와 엮인 코스를 보고, 로그인한 사용자는 저장할 수 있다.**

## 이 단계에서 만드는 것

| 기능 | PRD 번호 |
|---|---|
| 코스 상세 화면 | S-08 |
| 코스 저장 | S-08 |
| 명소 상세 → 코스 진입 연결 | S-08 |

> 코스를 사용자가 직접 만드는 화면(코스 생성 UI)은 만들지 않는다 (PRD 5장, MVP 아님).

## 하는 일

### 1. 코스 상세

- `GET /spots/{spotId}/courses` (계획) 로 명소 상세(Phase4)에서 코스로 진입한다.
- 코스는 명소 + 식당 1 + 카페 1 + 기타(소품샵·박물관 등)로 구성된다.

### 2. 코스 저장

- 저장/편집 API는 노션 명세에 명확히 없다. **구현 전에 BE와 반드시 경로를 확인한다.**
- 저장한 코스는 마이페이지(Phase7)의 "저장한 코스" 자리에 나타나도록 연결한다.

## 완료 기준 체크리스트

- [ ] 명소 상세 화면에서 코스로 진입할 수 있다
- [ ] 코스에 명소+식당1+카페1+기타 구성이 보인다
- [ ] 로그인한 사용자는 코스를 저장할 수 있다
- [ ] 저장한 코스가 마이페이지에 보인다
- [ ] 코스를 직접 만드는 화면은 없다
- [ ] `npm run lint`, `npm run build` 통과

## 넘어가기 전 확인

- 코스 저장/편집 API 경로는 이 문서 작성 시점에 확정되지 않았다. 임의로 경로를 추측해서 만들지 않는다 — BE에 먼저 확인한다.
- 코스에 포함된 주변 상권 정보는 BE가 저장하지 않고 그때그때 받아올 가능성이 높다(BE DETAIL_SPEC "주변 상권은 저장하지 않습니다"). Phase4의 주변 상권 처리 방식과 같은 결론이 나올 수 있으니 함께 확인한다.
