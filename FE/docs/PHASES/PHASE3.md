# Phase 3 — 검색

## 목표

**로그인 없이 명소와 작품을 검색할 수 있다.**

## 이 단계에서 만드는 것

| 기능 | PRD 번호 |
|---|---|
| 통합검색 (장소+작품) | S-03 |
| 드라마/영화 구분 조회 | S-03 |
| 자동완성 · 최근 검색어 | S-03 |

## 하는 일

### 1. 검색 실행

- `GET /search/spots`, `GET /search/works` (둘 다 계획, DETAIL_SPEC §9)를 호출해 결과를 **장소 섹션 / 작품 섹션**으로 나눠 보여준다.
- 검색어가 비어 있으면 요청을 보내지 않는다.
- 결과가 없으면 "검색결과가 존재하지 않습니다"를 보여준다.

### 2. 드라마/영화 필터

- 작품만, 드라마만, 영화만 골라볼 수 있는 선택지를 제공한다.

### 3. 자동완성 · 최근 검색어

- 입력하는 동안 이름 후보를 보여준다(자동완성).
- 로그인한 사용자의 검색어는 서버에 남는다(BE가 처리, FE는 검색 API만 정상 호출하면 됨).
- 비로그인 사용자의 최근 검색어는 기기(로컬 저장)에만 보관하고 서버로 보내지 않는다.

## 완료 기준 체크리스트

- [ ] 검색하면 장소/작품 결과가 섹션으로 나뉘어 보인다
- [ ] 드라마만/영화만 필터가 동작한다
- [ ] 검색어가 비어 있으면 검색 요청을 보내지 않는다
- [ ] 결과가 없으면 "검색결과가 존재하지 않습니다"가 보인다
- [ ] 자동완성이 동작한다
- [ ] 비로그인 사용자의 최근 검색어는 기기에만 저장된다
- [ ] 관련 유닛 테스트(검색 API 함수 성공/실패, 결과 없음 처리) 통과 (Vitest)
- [ ] `npm run lint`, `npm run build` 통과

## 넘어가기 전 확인

- 검색어를 FE가 번역해서 보내지 않는다. BE가 저장된 번역 이름으로 이미 매칭해준다(BE DETAIL_SPEC 3-2, "검색어를 먼저 번역하지 않는 이유" 참고).
- 명소 상세 화면(Phase4)이 아직 없다. 검색 결과를 클릭했을 때 이동은 임시로 처리해도 된다.
