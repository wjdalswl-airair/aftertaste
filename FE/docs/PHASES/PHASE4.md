## 하는 일

### 1. 카카오맵 연동

- 카카오 공식 JS SDK를 `index.html`에 `<script>` 태그로 로드한다. API 키는 `.env`에서 읽는다 (`.env` 파일 자체는 건드리지 않는다, CLAUDE.md Security Rules).
- 명소 좌표로 지도를 띄우고 마커를 표시한다.
- 길찾기 버튼은 `https://map.kakao.com/link/to/{name},{lat},{lng}` 링크로 연결한다. 앱이 있으면 앱으로, 없으면 모바일 웹으로 자동 대체된다.

### 2. 명소 정보 표시

- `GET /spots/{spotId}` (계획) 로 이름, 주소, 사진, 영업시간, 등장 작품 목록과 작품별 장면 설명, 작품 정보(제목/방영시기/주연배우/감독)를 표시한다.
- 없는 명소로 접근하면 "존재하지 않습니다"를 보여준다.

### 3. 리뷰 목록 (읽기 전용)

- `GET /spots/{spotId}/reviews` (계획) 로 목록과 평균 별점을 표시한다.
- 리뷰가 없으면 빈 목록(오류 아님).

### 4. 주변 상권

- `GET /spots/{spotId}/nearby` (계획) 자리를 만든다. **정확한 연동 방식은 미확정** — BE DETAIL_SPEC은 "카카오맵에서 그때그때 받아온다"고 되어 있어 별도 저장 API가 없을 수도 있다.

### 5. 즐겨찾기 버튼 (표시만)

- 버튼은 만들되, 클릭 시 로그인 여부만 확인한다. 비로그인이면 "로그인이 필요한 기능입니다" 안내. 실제 저장/취소 로직은 Phase5.

## 진행 상황 (2026-08-30)

**구현 완료.** BE가 `GET /api/places/{id}/` 하나로 명소 정보+작품+주변상권+리뷰를 전부 내려줘서, 계획에 있던 "리뷰 목록", "주변 상권" 별도 API는 필요 없었다.

| 파일 | 역할 |
|---|---|
| `src/api/spots.ts` | `getPlaceDetail` 응답 타입을 실제 API 구조에 맞게 확장 (`PlaceWork`/`NearbyPlace`/`PlaceReview` 등) |
| `src/lib/kakaoMap.ts` | 카카오맵 JS SDK 로더 (키 없으면 `null` 반환 → 폴백) |
| `src/types/kakao.d.ts` | 카카오맵 최소 ambient 타입 (npm 패키지 없이 직접 선언) |
| `src/components/FavoriteButton.tsx` | `initialFavorited`/`size`/`className` prop 추가 (상세 화면 재사용) |
| `src/pages/SpotDetailPage.tsx` | 명소 상세 화면 본체 |
| `src/App.tsx` | `/spots/:placeId` 라우트 추가 |
| `src/components/RecommendedSpots.tsx`, `TopPlacesCarousel.tsx`, `src/pages/SearchPage.tsx` | 명소 카드를 `/spots/:id`로 연결 |

Figma 실제 목업(node-id `102:712`)과 실제 데이터 모델이 안 맞던 부분들(입장료 필드 없음, 장면 설명 표시 자리 없음 등)은 `docs/DETAIL_SPEC.md` S-05에 기록해뒀다.

**카카오맵 키 필요**: `.env`에 `VITE_KAKAO_JS_KEY`를 추가해야 실제 지도가 뜬다(카카오 디벨로퍼스에서 JS 키 발급 + 플랫폼 도메인 등록 필요). 키가 없어도 나머지 화면은 정상 동작하고 지도 자리에 폴백 문구만 보인다.

**브라우저 확인 안 함**: 이 세션에서 Claude in Chrome 미사용, 로컬 BE DB에도 명소 데이터가 없어서(Phase3 때 확인) 코드/테스트 레벨로만 확인했다. 아래 체크리스트 중 실제 화면 확인이 필요한 항목은 표시해뒀다.

## 넘어가기 전 확인

- 주변 상권 API는 BE도 아직 확정 안 했다(BE DETAIL_SPEC §7 "아직 안 정한 것" 목록). 임의로 경로를 추측해서 만들지 말고, 화면 자리와 로딩/빈 상태 정도만 준비한다.
- 카카오맵 API 키를 코드에 직접 쓰지 않는다.
- 번역이 없거나 실패하면 한국어 원문이 그대로 온다 — FE가 별도로 감지하거나 처리하지 않는다.
