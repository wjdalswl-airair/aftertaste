# Compound Log

같은 실수가 반복되지 않도록, 각 단계 실행 결과에서 찾은 문제와 반복 패턴을 누적 기록하는 문서.

새 기록은 맨 위(최신순)에 추가한다. 기존 기록은 지우거나 고치지 않는다.

## 기록 형식

```
## {YYYY-MM-DD}
- tags: [{키워드1}, {키워드2}, ...]
- category: {구현 실수 | 테스트 놓침 | 문서·코드 불일치 | 리뷰 누락 | 하네스 개선 | ...}
- 문제: {무엇이 어떻게 잘못됐는지, 몇 번째 반복인지}
- 개선: {어떤 하네스를 어떻게 고쳤는지, 혹은 왜 아직 고치지 않았는지}
```
