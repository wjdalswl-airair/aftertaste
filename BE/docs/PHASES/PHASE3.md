# Phase 3 — 로그인 연계 개인화

## 목표

**사용자가 다시 찾아올 이유를 만든다.** 저장해둔 것이 있고, 내가 쓴 글이 있고, 나에게 맞춘 추천이 있으면 사람은 돌아온다.

## 이 단계에서 만드는 것

| 기능 | PRD 번호 |
|---|---|
| 즐겨찾기 | F-06 |
| 리뷰 (작성·수정·삭제 + 좋아요 + 신고) | F-07 |
| 검색이력 기반 추천 고도화 | F-04 나머지 |
| 마이페이지 | F-10 |
| 회원탈퇴 | F-11 |
| **Phase 2에서 비워둔 명예의 전당·Top10 채우기** | F-02 |

## 하는 일

### 1. 즐겨찾기 (전부 로그인 필요)

- 명소 저장하기 / 저장 취소 / 내 저장 목록 보기
- 같은 명소를 두 번 저장할 수 없다
- 이번 단계에서는 명소만 저장한다. 코스 저장은 Phase 4
- 저장 개수 제한, 폴더·태그 분류는 만들지 않는다 (PRD에서 "추후 추가")
- 비로그인 사용자가 누르면 "로그인이 필요한 기능입니다"

명소 상세 화면에 **내가 이미 저장했는지 표시**하는 것도 여기서 붙인다.

### 2. 리뷰

| 할 수 있는 일 | 로그인 |
|---|---|
| 명소의 리뷰 목록 보기 | 불필요 |
| 리뷰 쓰기 (별점 · 글 · 사진) | 필요 |
| 내 리뷰 고치기 · 지우기 | 필요 |
| 좋아요 누르기 · 취소 | 필요 |
| 신고하기 | 필요 |
| 내가 쓴 리뷰 모아보기 | 필요 |

**규칙**

- 한 명소에 리뷰를 여러 개 쓸 수 있다
- 실제로 방문했는지는 확인하지 않는다 (PRD에서 "추후 추가")
- 리뷰를 쓸 때 **어느 언어로 썼는지 함께 기록한다.** Phase 4의 리뷰 번역에서 쓴다. 나중에 기록하려 하면 이미 쌓인 리뷰의 언어를 알 수 없다
- 좋아요는 한 사람이 같은 리뷰에 한 번만
- 신고가 들어온 리뷰는 관리자가 확인하고 감출 수 있다. 감춰진 리뷰는 목록에 나오지 않는다
  - 신고 건수와 상관없이 관리자가 Django admin에서 수동으로 확인하고 감춘다. 일정 건수 이상이면 자동으로 숨기는 기능은 이번 단계에서 만들지 않는다 — **추후 팀원과 다시 정한다** (`docs/DETAIL_SPEC.md` 6-1 #13, 7장 #15)
- 남의 리뷰를 고치거나 지우려 하면 거부한다
- 리뷰 글자 수는 최대 1000자, 사진은 최대 3장까지다 (`docs/DETAIL_SPEC.md` 6-1 #14)

리뷰 목록을 **명소 상세 화면에 붙이고, 별점 평균도 함께 보여준다.**

### 3. 검색이력 기반 추천 고도화

Phase 2에서 쌓아둔 검색 기록을 여기서 쓴다.

| 상황 | 추천 방식 |
|---|---|
| 비로그인 | Phase 2에서 만든 것 그대로 (위치만) |
| 로그인 | 위치 + **검색 이력**을 함께 반영 |

검색 외에 **즐겨찾기와 리뷰 개수도 함께 반영한다** (PRD F-04). 이 데이터도 이 단계에서 생긴다.

### 4. 마이페이지

보여줄 것: 프로필 / 즐겨찾기 목록 / 내가 쓴 리뷰 / 국적·언어 설정
수정할 수 있는 것: 프로필(닉네임), 국적·언어

> 저장한 코스는 Phase 4에서 이 화면에 추가된다.

### 5. 회원탈퇴

**처리 방식이 조금 특이하다.** PRD에 "탈퇴해도 리뷰는 익명으로 남긴다"고 되어 있는데, 회원 기록을 통째로 지우면 그 사람이 쓴 리뷰들이 주인 없는 상태가 되어 같이 사라진다.

그래서 **회원 칸은 남겨두고, 이름·이메일 같은 개인정보만 비운 뒤 "탈퇴함" 표시**를 한다.

- 화면에는 작성자가 "탈퇴한 사용자"로 보인다
- 탈퇴한 사람은 로그인할 수 없다
- 같은 소셜 계정으로 다시 가입하면 **새 회원**으로 시작한다. 예전 즐겨찾기·리뷰는 돌아오지 않는다
- 탈퇴 전 확인 절차와 안내 문구는 만들지 않는다 (PRD에서 "추후 추가")

### 6. 명예의 전당 · Top10 채우기

Phase 2에서 자리만 비워둔 것을 여기서 채운다. 이제 재료가 생겼기 때문이다.

| 구성 요소 | 계산 기준 |
|---|---|
| 명예의 전당 | 그 달에 좋아요가 가장 많은 후기의 사진 |
| Top10 캐러셀 | 즐겨찾기가 가장 많은 명소 10곳 |

## 완료 기준 체크리스트

**즐겨찾기**
- [ ] 로그인한 사람이 명소를 저장하고 취소할 수 있다
- [ ] 내 저장 목록이 나온다
- [ ] 같은 명소를 두 번 저장해도 중복으로 쌓이지 않는다
- [ ] 저장하지 않은 명소를 취소해도 오류가 나지 않는다
- [ ] 로그인하지 않고 저장을 누르면 "로그인이 필요한 기능입니다"가 나온다
- [ ] 명소 상세에서 내가 이미 저장했는지 보인다

**리뷰**
- [ ] 로그인 없이 리뷰 목록을 볼 수 있다
- [ ] 로그인한 사람이 별점·글·사진으로 리뷰를 쓸 수 있다
- [ ] 내 리뷰를 고치고 지울 수 있다
- [ ] 남의 리뷰를 고치거나 지우려 하면 거부된다
- [ ] 한 명소에 리뷰를 여러 개 쓸 수 있다
- [ ] 좋아요를 두 번 눌러도 하나로만 센다
- [ ] 같은 리뷰를 여러 번 신고해도 한 번만 접수된다
- [ ] 관리자가 감춘 리뷰는 목록에 나오지 않는다
- [ ] 리뷰마다 어느 언어로 쓴 글인지 기록되어 있다
- [ ] 명소 상세에 리뷰 목록과 별점 평균이 나온다

**추천 고도화**
- [ ] 로그인한 사람의 추천에 검색 이력이 반영된다
- [ ] 즐겨찾기·리뷰 개수도 반영된다
- [ ] 검색 기록이 없는 새 회원에게도 추천이 나온다 (위치만으로)
- [ ] 비로그인 추천은 Phase 2와 똑같이 동작한다

**마이페이지 · 탈퇴**
- [ ] 프로필, 즐겨찾기 목록, 내가 쓴 리뷰, 국적·언어 설정이 한 화면에 나온다
- [ ] 닉네임과 국적·언어를 바꿀 수 있다
- [ ] 탈퇴하면 로그인할 수 없다
- [ ] 탈퇴한 사람의 리뷰가 사라지지 않고 "탈퇴한 사용자"로 남는다
- [ ] 탈퇴한 계정으로 다시 로그인하면 새 회원으로 시작된다

**메인 화면 채우기**
- [ ] 명예의 전당에 그 달 좋아요가 가장 많은 후기의 사진이 나온다
- [ ] Top10에 즐겨찾기가 가장 많은 명소 10곳이 나온다
- [ ] 리뷰나 즐겨찾기가 아직 없어도 화면이 깨지지 않는다

## 넘어가기 전 확인

- 화면은 아직 한국어로만 나온다. 다국어는 Phase 4다.
- 리뷰의 "어느 언어로 썼는지" 기록을 빠뜨리면 Phase 4에서 번역을 붙일 때 막힌다. 반드시 확인한다.
