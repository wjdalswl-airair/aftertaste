# Phase 5 — 런칭 준비

## 목표

**내 컴퓨터에서만 되던 것이 진짜 주소로 접속해도 되게 만든다.**

기능을 새로 만드는 단계가 아니다. 앞에서 만든 것을 바깥에 내놓는 단계다.

> 요청하신 파일은 PHASE1~4였는데, 내용에 Phase 5까지 주셔서 파일을 하나 더 만들었습니다. 필요 없으시면 지우시면 됩니다.

## 하는 일

### 1. 카카오맵 · Firebase에 주소 등록

카카오맵과 Firebase(로그인 담당)는 **"어느 주소에서 우리 서비스를 부를 것인지" 미리 등록해둔 곳에서만 동작한다.** 아무 데서나 쓰이면 남이 우리 이름으로 요금을 쓸 수 있기 때문이다.

개발할 때는 내 컴퓨터 주소만 등록해두고 쓴다. 그래서 **진짜 주소로 배포하는 순간 로그인과 지도가 한꺼번에 멈춘다.** 배포 직후 가장 자주 터지는 문제다.

- 카카오: 실제 서비스 주소를 등록한다
- Firebase: 실제 서비스 주소를 로그인 허용 목록에 등록한다
- 개발용 주소도 지우지 말고 같이 둔다. 지우면 개발 중에 로그인이 안 된다

### 2. HTTPS 확인

주소가 `https`로 시작하게 만드는 일이다. 자물쇠 표시가 붙는 그것이다.

**단순히 보안 때문만이 아니다.** 소셜 로그인과 위치 권한은 `https`가 아니면 아예 동작을 거부한다. 즉 이게 안 되면 **Phase 1의 로그인과 Phase 2의 위치기반 추천이 통째로 멈춘다.**

### 3. 배포 후 실제로 눌러보기

앞 단계의 완료 기준은 개발 환경에서 확인한 것이다. **배포된 진짜 주소에서 다시 한번 눌러봐야 한다.** 위 두 가지 문제는 배포하기 전에는 드러나지 않는다.

## 완료 기준 체크리스트

**주소 등록**
- [ ] 카카오에 실제 서비스 주소가 등록되어 있다
- [ ] Firebase 로그인 허용 목록에 실제 서비스 주소가 등록되어 있다
- [ ] 개발용 주소도 함께 남아 있어서 개발 중에도 로그인이 된다

**HTTPS**
- [ ] 실제 주소가 `https`로 열린다
- [ ] `http`로 들어가도 `https`로 넘어간다

**배포된 주소에서 다시 확인**
- [ ] 구글 로그인이 된다
- [ ] 카카오 로그인이 된다
- [ ] 위치 권한 요청이 뜨고, 허용하면 주변 명소가 나온다
- [ ] 위치 권한을 거부해도 화면이 깨지지 않는다
- [ ] 지도가 뜨고 명소 위치가 표시된다
- [ ] 길찾기를 누르면 카카오맵으로 넘어간다
- [ ] 검색이 된다
- [ ] 리뷰 사진이 올라가고 다시 보인다
- [ ] 공유 링크를 다른 기기에서 열면 로그인 없이 보인다

## 아직 안 정한 것

- 실제 서비스 주소를 무엇으로 할지
- 개인정보·위치정보 처리 방침 문서 (PRD N-02에서 미정)
