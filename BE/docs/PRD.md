## 1. 서비스 개요

영화·드라마 촬영지를 찾아보고, 그 주변 상권까지 묶은 관광 코스를 추천받는 서비스입니다.
작품을 보고 남은 여운(aftertaste)을 실제 여행으로 이어주는 것을 목표로 합니다.

### 1.1 해결하려는 문제
- 작품에 나온 장소가 어디인지 찾기 어렵다.
- 촬영지를 찾아도 그 주변에서 무엇을 할 수 있는지 따로 검색해야 한다.
- 외국인 이용자는 한국어로만 정리된 정보에 접근하기 어렵다.

### 1.2 핵심 가치 제안
이 서비스는 한국 드라마/영화의 촬영지를 방문하여 여운을 느끼고 싶은 사람에게 관광정보를 제공한다. 

### 1.3 주요 타깃 사용자
- 한국 드라마·영화를 보고 한국 여행을 계획하는 관광객

### 1.4 성공 지표
가입전환률

## 3. 기능 요구사항

### F-01. 소셜 로그인 / 회원가입
- Google 계정으로 로그인할 수 있다.
- Apple 계정으로 로그인할 수 있다.
- **전화번호 입력 없이** 회원가입을 완료할 수 있다.
- 처음 로그인한 사용자는 별도 절차 없이 바로 회원으로 등록된다.

- 가입 직후 추가로 받을 정보 없음
- 이메일/비밀번호 방식은 제공하지 않는다. 
- 약관·개인정보 동의는 가장 첫 화면에 등장한다. 
- **카카오 로그인**: 목업(`screenshots/여운.png`) 로그인 화면에는 Google·Apple·Kakao 세 가지가 있으나, 이번 범위는 Google·Apple만이다. 카카오는 프론트엔드가 이미 붙여 두었으면 나중에 백엔드를 추가한다. (2026-08-28)

---

### F-02. 메인 화면
로그인 없이 이용할 수 있으며, 다음 네 가지로 구성됩니다.

| 구성 요소 | 설명 |
|---|---|
| 슬라이드 배너 | 상단에 노출되는 홍보/기획 영역 |
| 명예의 전당 | 인기 명소 또는 인기 작품을 강조해 보여주는 영역 |
| 국적 선택 | 사용자가 자신의 국적을 고르는 영역. 이후 번역 언어의 기준이 됨 |
| Top10 캐러셀 | 상위 10개 항목을 좌우로 넘겨 보는 영역 |

- 명예의 전당 선정 기준은 해당 **주(週)**에 좋아요 수가 가장 많은 후기의 대표 사진이다. (2026-08-28: 월→주로 변경. 목업 문구도 "금주의 명예의 전당")
- 명소 TOP10은 즐겨찾기가 가장 많은 명소 10가지를 말한다. 
- 배너에 넣을 콘텐츠는 관리자가 주간 콘텐츠를 입력한다. 
- 국적을 선택하지 않고 넘어간 사용자에게는 한국어를 기본값으로 제공한다
- 목업 홈 상단의 **날씨 위젯**(예: "인천 · 흐림 25°")은 **백엔드 작업 없음** — 프론트엔드가 위치 정보로 날씨 API를 직접 호출한다. (2026-08-28. API 키 보안·캐싱이 문제가 되면 그때 백엔드 프록시를 다시 검토)

---

### F-03. 검색
- 로그인 없이 이용할 수 있다.
- **통합검색**: 하나의 검색창에서 장소와 작품을 함께 찾을 수 있다.
- **구분 조회**: 드라마와 영화를 나누어 볼 수 있는 선택지를 함께 제공한다.
- 로그인한 사용자의 검색 기록은 추천 고도화(F-04)에 활용된다.
- 검색 결과에서 장소와 작품을 섹션으로 나누어 보여준다.
- 결과가 없을 때는 "검색결과가 존재하지 않습니다"라고 발행한다. 
- 자동완성·최근 검색어를 제공한다.
- **추천(인기) 검색어**: 검색 홈 화면에 해시태그 형태로 노출한다. 관리자가 손으로 고르는 것이 아니라 **검색 기록을 집계해 자동 산출**한다. (2026-08-28, 목업 "추천 검색어" 영역)

---

### F-04. 추천 (위치 기반)

추천은 **사용자의 현재 위치**를 기준으로 동작하며, 상황에 따라 세 갈래로 나뉩니다.

| 상황 | 추천 방식 |
|---|---|
| 비로그인 + 위치 권한 **허용** | 현재 위치 주변의 촬영 명소를 추천 |
| 비로그인 + 위치 권한 **거부** | 위치 없이 제공 가능한 기준으로 추천 |
| 로그인 + 위치 권한 허용 | 위치 + **검색 이력**을 함께 반영한 개인화 추천 |

- 추천 기능 자체는 로그인 없이도 이용할 수 있다.
- 검색 이력 기반 고도화는 로그인한 사용자에게만 적용된다.
- 위치 권한을 거부했을 경우 비로그인 상태의 추천과 동일하다.
- 위치 권한은 앱 진입 즉시 등장한다
- 추천 개수는 3, 반경은 현위치와 가장 가까운 위치의 거리를 기준으로 한다
- 이력 기반 추천에 검색 외에 즐겨찾기, 리뷰 개수 등을 반영한다

---

### F-05. 명소 상세
- 로그인 없이 이용할 수 있다.
- 카카오맵과 연동된 지도 위에서 명소의 상세 정보를 확인할 수 있다.
- 해당 명소가 등장한 작품 정보를 함께 볼 수 있다.
- 상세 화면에 반드시 들어가야 할 정보 목록 (예: 명소명, 주소, 등장 작품의 간단한 설명(제목, 방영시기, 주연배우, 감독), 등장 장면 설명, 사진, 영업시간, 주변 상권, 리뷰)
- 여운 API 명세서 기준 추가 필드: 추천 방문 시간, 사진 팁, 주의할 점 (관리자 입력, 번역 안 함. 2026-08-28, `DETAIL_SPEC` 6-1 #25)
- 지도에서 길찾기까지 카카오맵 라우팅을 이용해서 기능을 제공한다.
- 사진은 어디서 확보할지 (운영자 등록 & 사용자 리뷰 사진)

---

### F-06. 즐겨찾기
- **로그인이 필요하다.**
- 마음에 드는 명소를 저장해 두고 나중에 다시 볼 수 있다.
- 저장한 목록은 마이페이지에서 확인한다.

- 비로그인 사용자가 즐겨찾기를 누르면 "로그인이 필요한 기능"임을 명시한다
- 명소 외에 코스도 저장 가능
- 저장 개수 제한이나, 폴더·태그 분류 기능은 추후 추가한다.

---

### F-07. 리뷰
- **작성·수정·삭제 모두 로그인이 필요하다.**
- 방문한 명소에 대한 후기를 남길 수 있다.

- 리뷰 **조회**는 비로그인도 가능하다 (초안은 가능 기준)
- 리뷰 구성 요소: 별점 / 텍스트(**최대 500자**) / 사진(**최대 5장**). (2026-08-28 확정, 목업 "0/5", "14/500")
- 한 명소에 리뷰를 여러 개 쓸 수 있다
- 실제 방문 여부를 확인할 방법은 없다 - 추후 추가
  - 마이페이지 "방문 인증한 촬영지 수"는 실제 방문 인증 기능이 아니라, **내가 리뷰를 쓴 서로 다른 명소의 개수**를 뜻한다. (2026-08-28)
- **부적절한 리뷰 신고·삭제 정책** 
- 다른 언어로 쓰인 리뷰를 번역해서 보여준다 (F-10과 연결)

---

### F-08. 코스 추천
- 촬영 명소와 그 주변 상권을 묶어 하나의 관광 코스로 제안한다.

- 코스는 근처 식당 1 + 카페 1 + 그 외(소품샵, 박물관, 타 명소 등)로 구성된다. 
- 코스는 사용자 등록, 관리자 등록, ai 추천을 이용하여 만든다 - MVP 아님
- 코스를 저장하거나 편집할 수 있다
- 코스 생성 시에만 로그인이 필요하다
- 명소 상세 화면에서 코스로 진입한다.
- 코스 구성 개수는 **고정**이다(명소 anchor + 식당 1 + 카페 1 + 그 외 1). 목업의 가변 개수·드래그 재정렬 UI는 이번 범위 아님. (2026-08-28, `DETAIL_SPEC` 6-1 #17)
- 목업의 **AI 코스 추천 화면**(예상 소요시간·이동거리·구간별 도보시간·5곳 타임라인·추천 카페/맛집/숨은 명소·"코스 저장"/"길안내 시작")은 **이번 범위 제외**다. 현황은 `DETAIL_SPEC` 6-2에 정리해 둔다. (2026-08-28)

---

### F-09. 외부 공유
- 명소, 리뷰, 코스를 서비스 밖으로 공유할 수 있다.

- 명소 / 코스를 공유할 수 있다
- 어디로 공유하는가 (링크 복사 - MVP, 이외 채널은 추후 추가)
- 공유받은 사람이 로그인 없이 내용을 볼 수 있다

---

### F-10. 마이페이지
- **로그인이 필요하다.**
- 내 정보와 활동 내역을 한곳에서 확인한다.
- 프로필, 즐겨찾기 목록, 내가 쓴 리뷰, 국적/언어 설정, 저장한 코스가 포함된다
- 프로필에서 수정할 수 있는 항목은 프로필, 국적과 언어이다.
- 프로필 상단에 활동 요약 두 개를 보여준다 (2026-08-28, 목업):
  - **방문 인증한 촬영지 수** = 내가 리뷰를 쓴 서로 다른 명소의 개수 (F-07 참고, 실제 방문 인증 아님)
  - **제안한 코스 수** = 내가 만든 코스의 개수
- 닉네임은 **최대 20자**다. (2026-08-28, 목업 "3/20")

### F-11. 회원탈퇴
- **로그인이 필요하다.**
- 사용자가 직접 탈퇴할 수 있다.
- 탈퇴 시 작성한 리뷰를 익명으로 남긴다.
- 탈퇴 후 같은 계정으로 재가입할 수 있다
- 탈퇴 전 확인 절차와 안내 문구는 추후 추가할 예정이다

## 4. 비기능 요구사항

### N-01. 다국어 번역 ⭐ (핵심 차별점)
- 사용자가 선택한 **국적에 맞춰** 화면과 콘텐츠를 자연스러운 문장으로 번역해 제공한다.
- 단, **한국 고유명사는 뜻을 옮기지 않고 소리 나는 대로(음역) 표기한다.**
  - 예: `경복궁` → `Gyeongbokgung` (○) / `Gyeongbok Palace`, `Scenery Palace` (×)
  - 이유: 현지에서 길을 묻거나 표지판을 찾을 때 실제로 통하는 표기여야 하기 때문.

- 가능한 많은 언어를 지원한다. 
- 고유명사는 지명과 순우리말을 음역한다.  
- 사용자가 만든 콘텐츠(리뷰)도 번역 대상이다.
- 국적 선택과 화면 언어를 하나로 묶는다.

### N-02. 그 외
(추후 추가 예정)
- 화면 로딩 체감 속도 기준
- 지원 기기·화면 크기 (모바일 우선 여부) ⭐
- 개인정보·위치정보 처리 방침 ⭐
- 접근성 고려 수준
