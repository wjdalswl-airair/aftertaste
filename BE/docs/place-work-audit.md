## 2. 작품 중복 (95 그룹) — `title_key` 병합으로 일괄 해소

구두점·공백·붙임표만 다르고 사실상 같은 작품이 2~3개 Work로 쪼개짐. 대부분
**KCISA 원본(촬영지 연결 있음) + KMDB 재수집본(연결 0곳)** 조합.

예:
- `세상 어디에도 없는 착한남자`(#421, 7곳) / `세상 어디에도 없는 착한 남자`(#913, 2곳)
- `안녕 나야!`(#515, 17곳) / `안녕 나야`(#1063, 1곳)
- `위대한 유혹자`(#623, 18곳) / `위대한유혹자`(#624, 1곳)
- `당신 거기 있어줄래요`(#181, 10곳) / `당신 거기 있어줄래요?`(#1335, 1곳) / `당신 , 거기 있어줄래요`(#3005, 0곳)
- `공동경비구역JSA`(#56, 6곳) / `공동 경비 구역 J.S.A`(#3109, 0곳)

**전수 검토 결과 서로 다른 작품이 섞인 경우 없음** — `normalize_title_for_match`(괄호·구두점·공백
제거)로 묶으면 안전하게 병합 가능. 부제가 다른 작품(`신과함께: 죄와 벌` vs `인과 연`)은 글자가
보존되므로 안 묶임.

병합 규칙: **연결 촬영지가 많은 쪽을 정본**, 동수면 낮은 id. 나머지의 `PlaceWork`·`WorkTranslation`을
정본으로 옮기고(중복 연결은 `unique_together`로 스킵) 중복 Work 삭제.
