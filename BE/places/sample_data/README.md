# 샘플 데이터 안내

이 폴더의 JSON 파일은 `import_places` 명령어가 제대로 동작하는지 로컬에서 확인하기 위해
**직접 만든 가짜 데이터**다. 실제 공공데이터 API(KOBIS, 경기 데이터 드림, 한국문화정보원 등)를
호출해서 받은 데이터가 아니고, 그 API들의 실제 응답 필드명이 이것과 같다고 확인된 것도 아니다.

실제 API를 연동할 때는 `docs/DETAIL_SPEC.md` 7장 #1이 마저 정해진 뒤,
각 출처의 실제 응답 필드에 맞춰 `import_places.py`의 `_get_source_id`/`_parse_place_fields`를
다시 맞춰야 한다.

- `sample_places_v1.json`: 첫 가져오기 테스트용. 정상 데이터, 좌표가 이상한 값인 데이터,
  원본 번호가 없는 데이터를 섞어뒀다.
- `sample_places_v2.json`: 같은 명소를 다시 가져오는 상황(재수집) 테스트용. 일부 항목은
  주소가 빠져 있다 — 재수집 시 빈 값으로 기존 값을 덮어쓰지 않는지 확인하기 위함이다.
